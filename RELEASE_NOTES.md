# Height Axis 1.2.1

A Blender viewport height ruler and reference figure with view-left following and world-space Freeze.

- Measure world-Z height beside the current selection, including combined selections.
- Follow the mouse on the left when nothing is selected.
- Load Blend, FBX, OBJ, glTF/GLB or STL as a configurable, shaded reference figure.
- Freeze both guides in world space, including from the sidebar in mouse mode.
- Save reference data and frozen placement with the blend file.
- English interface with optional Simplified Chinese translation.

Install `height-axis-1.2.1.zip` through Blender's **Preferences → Get Extensions → menu → Install from Disk**, then open **N → Scale**. The ZIP is the installer; the source archives are for development. `SHA256SUMS.txt` contains the package checksum.

Manifest minimum: Blender 4.5. Tested: 5.1.2 and 5.2.2 LTS. The figure is a blue viewport reference; source textures and animation are not displayed. See the README for measurement and instance limits.

## 简体中文

Height Axis 1.2.1 是 Blender 的视口高度尺和参考人物插件，支持屏幕左侧跟随及世界位置冻结。

- 在选中物体左侧测量世界 Z 高度，支持多选整体范围。
- 未选中时在鼠标左侧跟随。
- 加载 Blend、FBX、OBJ、glTF/GLB 或 STL 作为可调身高的蓝色立体参照。
- 尺子和人物可同时冻结在三维位置，支持从侧栏冻结最后的鼠标参照。
- 参照数据与冻结位置随 blend 文件保存。
- 英文界面，包含随 Blender 设置使用的简体中文翻译。

下载 `height-axis-1.2.1.zip`，在 **Preferences → Get Extensions → 菜单 → Install from Disk** 安装，然后进入 **N → Scale**。该 ZIP 是安装包，源码压缩包供开发使用；`SHA256SUMS.txt` 提供校验值。

清单最低版本为 Blender 4.5，实际测试 5.1.2 与 5.2.2 LTS。人物只作蓝色视口参照，不显示源贴图和动画；测量及实例边界见 README。
